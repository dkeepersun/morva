# Story 4.4: 机器读取七阶段模拟报告

Status: done

## Story

As a 自动化验证工具开发者,
I want 以稳定 JSON 读取场景模拟过程和结果,
so that 我可以准确展示状态变化、失败阶段及源码责任位置。

## Acceptance Criteria

见 `_bmad-output/planning-artifacts/epics.md#Story-4.4`。

## Implementation Notes

- `morva simulate --format json`：统一 envelope + `report`（system/scenario/action、固定顺序的七阶段各标 passed/failed/not_run、确定排序的 changes 与最终 state、`failure` 含 phase/message/真实源位置）。
- 值使用显式类型标签：`boolean`、`integer`（十进制字符串，避免无类型 scalar 推断）、`enum`（type+member）。state 来自 BTreeMap，天然确定排序。
- 失败 span 经 `Locator::try_location` 回映真实文件本地 span（项目不暴露 virtual offset）；scenario 未知/歧义/不可绑定复用 machine diagnostic 结构退出 1；IO/usage 复用 error envelope 退出 2。短路未求值分支不产生虚假 failure（运行时语义未动）。
- stdout 无 PASS/FAIL、阶段表或 marker 文本；无 `--format json` 时人类输出与退出码不变。

## Verification

- 197 workspace tests、fmt、locked strict Clippy 全绿。
