# Story 4.3: 机器读取语义摘要与能力清单

Status: done

## Story

As a 工具集成开发者,
I want 以 JSON 查询模型摘要和 Morva 能力边界,
so that 工具可以区分已验证、仅识别和不支持的内容。

## Acceptance Criteria

见 `_bmad-output/planning-artifacts/epics.md#Story-4.3`。

## Implementation Notes

- `morva inspect --format json`：统一 envelope，`diagnostics`（与 check 相同的 coverage warnings）与 `summary` 分离；`summary.modeled` 按构造类别输出名称与计数（enum/entity/action/scenario，含 soft_behavior_count），`summary.unmodeled` 输出结构化分类、名称、真实源与本地 span 的条目及计数——不含被跳过正文。warning-only 仍 success true 退出 0；模型/IO/usage 错误复用 4.1 envelope 与退出码。
- `morva capabilities --format json`：序列化同一 `morva_core::capabilities()` 清单，不读文件；envelope 同时携带 `schema_version`（morva.cli 协议版本）与 `capabilities.version`（能力模型版本），语义在 docs/cli.md 分别定义——无重复判断表（人类、JSON、warning、inspect 分类均消费同一 core 常量）。
