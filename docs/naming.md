# Naming review

The project, language, CLI, and full source extension use one name:

```text
Morva / morva / .morva
```

Morva is five characters and can be read as Model, Requirements, Validation, and Architecture. The expansion is a design reminder, not a product slogan.

## Quick public collision check

On 2026-08-10, a short list of 21 candidates was checked for obvious collisions with programming languages, developer tools, GitHub projects, package registries, and common language extensions. No established programming language or prominent developer tool named Morva was found. Exact `morva` packages were not found on npm, PyPI, or crates.io, and `.morva` was absent from GitHub Linguist's extension list.

There are a few small, unrelated repositories using the name. The base `.org` and `.io` domains are also not freely available, so the name is clean for this engineering project rather than globally unused. This is a practical public check, not trademark advice.

Alternatives retained during the check were Telyn, Axyra, Evra, and Rylin. Names rejected for direct or nearby conflicts included Nex, CUE, Pkl, Rill, Noema, Tersa, and Semra.

Sources used for the reproducible baseline:

- [GitHub repository search](https://github.com/search?q=morva+in%3Aname&type=repositories)
- [GitHub Linguist language and extension registry](https://github.com/github-linguist/linguist/blob/main/lib/linguist/languages.yml)
- [npm registry](https://registry.npmjs.org/)

The name should be checked again before the first public release, especially in package registries, editor marketplaces, and relevant trademark databases.
